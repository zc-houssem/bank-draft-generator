Electron-Vite-React-Sqlite3

A project template for React built with Vite, including electron, sqlite, offline maps, and three.

# Installation

Install dependencies using yarn:

```bash
yarn
```

Development

```bash
yarn dev
```

# Debugging Tips

    Use the shortcut control + shift + win + c on a webpage to select relevant page elements, then open VSCode to navigate to the corresponding code line.

## 🔧 npm/yarn Configuration Commands
